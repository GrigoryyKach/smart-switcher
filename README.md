# Smart Switcher

Локальный автопереключатель раскладки EN ⇄ RU для Windows, аналог Punto Switcher.
Набрали `ghbdtn` и нажали пробел — получили `привет`, а раскладка сама сменилась на русскую.
Работает полностью офлайн.

## Запуск

```bash
npm install
npm start
```

`npm start` компилирует нативный хелпер и запускает приложение. Компилятор C# уже встроен в Windows (.NET Framework 4.x), ставить ничего не нужно. Иконка появится в трее: щелчок открывает настройки, правая кнопка — меню.

Нужно, чтобы в Windows были установлены английская и русская раскладки.

## Что умеет

- **Автоисправление** после пробела, Enter или Tab (что именно — выбирается в настройках).
- **Pause** (или «Shift дважды», «Ctrl дважды»):
  - во время набора слова — переводит его в другую раскладку;
  - сразу после автоисправления — отменяет его, а слово запоминается как исключение;
  - после пробела — исправляет последнее слово.
- **Shift+Pause** — перекодирует выделенный текст целиком.
- Исправляет вместе со следующим словом и предыдущий короткий предлог: `yf cnjkt` → `на столе`.
- Исключения для слов и для программ: игр, терминалов, менеджеров паролей.
- Проверка слова прямо в настройках: видно, что программа сделает и почему.
- Журнал исправлений за сеанс (хранится только в памяти).

## Как устроено

```
Electron (src/)                         Нативный хелпер (helper/, C#)
 ├ трей, окно настроек      JSON по     ├ глобальный хук клавиатуры и мыши
 ├ config.json в %APPDATA%  ◄────────►  ├ буфер текущего слова
 └ журнал, статистика       stdin/out   ├ детектор: словари + триграммная модель
                                        └ замена: Backspace×N → Unicode-ввод → смена раскладки
```

- `helper/src/Engine.cs` — хук, буфер, автозамена, отмена, выделенный текст.
- `helper/src/Detector.cs` — решает, верна ли раскладка: сначала словари, затем триграммная модель с нормировкой по языку.
- `helper/dict/*.txt` — словари, встраиваются в exe. Можно дополнять, по одному слову или через пробел.
- `src/main.js` — трей, запуск и перезапуск хелпера, конфиг; `src/settings/` — интерфейс.

Если Electron закроется, хелпер тоже завершится, когда закроется его stdin: висящих хуков не остаётся.

## Сборка .exe

```bash
npm run package
```

Результат: `dist/SmartSwitcher-win32-x64/SmartSwitcher.exe`. Папку можно перенести куда угодно, запускать exe внутри неё.

## Тесты

```bash
npm run selftest
```

Проверяет детектор на словарях и на словах вне словаря. Для каждого слова смотрит, что правильно набранное слово не трогается, а набранное не в той раскладке исправляется.

```bash
npm run e2e
```

Сквозной тест с настоящим хуком. Открывает своё окно и «печатает» в него через SendInput 16 сценариев. Печатает только пока это окно активно, поэтому во время теста не трогайте клавиатуру и мышь.

## Ограничения

- Окна, запущенные от администратора, недоступны хелперу без прав администратора (ограничение Windows UIPI).
- Определить поле пароля нельзя, поэтому менеджеры паролей стоит добавить в исключения.
- Пока встроены только частотные словари (~1700 EN и ~1350 RU слов). Для слов вне словаря работает статистическая модель, она чаще пропускает слово, чем ошибается.

## Обновления и NIMVORO

Утилита входит в набор [NIMVORO](https://github.com/GrigoryyKach/nimvoro): лаунчер ставит её в один клик и обновляет.
При запуске программа проверяет последний [релиз](https://github.com/GrigoryyKach/smart-switcher/releases/latest) (переключатель на странице «О программе»).
Если есть новая версия, кнопка «Обновить» передаёт обновление лаунчеру, а без лаунчера открывает страницу релиза.

Релиз собирается GitHub Actions при пуше тега: поднимите версию в `package.json`, затем `git tag v{версия} && git push --tags`.
